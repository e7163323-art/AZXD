🎈 מפתח API ל-Balloni

התחבר עם Google וקבל מפתח אישי כדי להשתמש ב-AI מתוכנה אחרת. מפתח אחד לכל חשבון; יצירת מפתח חדש מבטלת את הקודם.

הכניסה משמשת רק לזיהוי (כתובת המייל נשמרת כשם המפתח). שום סיסמה לא עוברת דרכנו.
מחובר:

שימוש
curl /v1/chat/completions \
 -H "Authorization: Bearer bal-..." \
 -H "Content-Type: application/json" \
 -d '{"messages":[{"role":"user","content":"שלום"}]}'
שיחה בלבד, עד 30 בקשות בדקה, תשובה עד 1024 טוקנים. המודל בשרת הוא מודל פתוח של Cloudflare.
